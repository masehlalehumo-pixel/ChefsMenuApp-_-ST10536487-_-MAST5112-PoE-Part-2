Chef's Menu Board (MAST5112 PoE Part 2)

A React Native / Expo mobile application designed for chefs to manage, add, and calculate menu items dynamically.

 Features

* Add Menu Items: Capture dish name, detailed description, course selection, and price.
* Course Selection: Interactive chip selectors (`Starter`, `Main Course`, `Dessert`).
* Dynamic Menu Display: Real-time updates using React state (`useState`) and `FlatList`.
* Real-time Metrics: Automatic calculation of total items and average dish prices.
* UX & Validation: Form field validation, numeric price checks, success alerts, and custom empty state handling.

Tech Stack & Dependencies

* Framework: React Native (Expo SDK)
* Language: TypeScript (`.tsx`)
* Components: `FlatList`, `SafeAreaView`, `KeyboardAvoidingView`, `Alert`
